# 双议题独立复审

目标：两个subagent分别独立判断根float/memory及固定子模块的JSON生成是否忠实表达Sail模型控制流，并评估浮点/内存专项支持。

范围：当前固定提交、源码到IR对应、执行/编码/具体化、初后态及异常、采样/遗漏、JSON可重放性、GCC和Clang双汇编。区分语义错误与覆盖证据不足，不以gen数量或退出0代替源码控制流覆盖。

分工：float agent只写本目录float/，memory agent只写memory/；源码、分支、现有产物只读。各自自行取证并独立交付分级问题、具体位置、复现与修改意见，不向对方借用结论。主agent只调度、核对证据与汇总，不代替独立判断。不得产生二级agent。

验证：先核实精确版本与工作区；新探针输出独立目录，避免共享target并行构建；有限预算运行，记录未测边界。已有报告仅作参考，不能替代当前源码核实。
