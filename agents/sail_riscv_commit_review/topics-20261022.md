## 本轮验证

最终2＋14个精确中间提交分别做普通及SYMBOLIC全模型严格类型检查，**32次均退出0**，每层提交前核对暂存tree并在检查后再次核对未变。工具使用既有补丁版Sail0.20.1，实际编译器与launcher哈希、缓存来源见 [toolchain.json](topics-20261022/toolchain.json)。本轮复制旧同工具链约束缓存到独立临时目录，不改原缓存。

各次实际命令在对应工作树的 `model/` 下执行：

```sh
sail --no-warn --no-color --strict-var --strict-bitvector --strict-exponentials \
  --require-version 0.20.1 --memo-z3-path <本轮对应分支和模式的独立缓存> \
  --all-modules --just-check [-D SYMBOLIC] riscv.sail_project
```

此处`sail`表示证据中记录的补丁版完整可执行路径，不代表系统默认编译器。执行脚本中的实际argv和日志保存在 [执行记录](topics-20261022/commits.json)，32份日志哈希均已复核。
