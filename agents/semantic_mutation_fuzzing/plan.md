## 目标

对照 2025–2026 年公开 CPU fuzzing 工作，判断把 Isla 生成物作为变异种子，以及用符号执行反馈指导变异的价值、已有先例和可检验的研究问题。

## 范围与热点

- 优先讨论 RISC-V 向量、内存功能错误；瞬态执行和侧信道另列其观测与判错要求。
- 项目入口：`agents/findings.md`、内存 P1/P2/P3 与 P4/P6 计划、见证随机化独审及分支核查。
- 源码只读核对：`isla/src/isarch/exec.rs` 的生成物字段、`isla/isla-lib/src/executor/execution_limits.rs` 的路径签名；内存和随机化能力按各自工作树核对。
- 保留原工作区全部修改；不合并分支，不修改模型、IR、执行器或 harness。

## 步骤与验证

1. 区分正式会议年份与预印本公开年份，优先读会议页及作者公开全文。
2. 比较种子来源、变异单位、反馈来源、求解器角色与判错机制。
3. 建立项目可复用能力和缺口映射，给出分层闭环与具体例子。
4. 提出同预算消融实验；调查结论不记功能 PASS。
