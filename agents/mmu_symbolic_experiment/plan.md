# Sv39 全符号页表实证计划

目标：使用指定的现成 isarch 与 rv64d.ir，对相同 LD 编码做 Bare、具象恒等页表、全符号页表对照，记录路径、时间与具体 PTE 见证。

范围：只新增实验配置、运行与分析脚本及文档；不修改或重建生产二进制、IR。实验产物位于 `.worktree/mmu-symbolic-experiment/`。

热点：MemoryBuilder Sv39 Identity 只映射低 1GiB，叶 PTE 设置 U 位。因此选择低地址并统一补充对应 RAM 属性与内容区域，设置 SUM。Supervisor 的 satp 固定为指定值。

步骤：冻结输入哈希及源码状态；检查命令与统计字段；单线程、60 秒预算运行三组；提取成功与异常见证，按 Sv39 手工算法独立检查 PTE；整理结论和限制。

验证：检查实际退休状态、页表读取事件及最终数据地址；核对过滤、错误、未完成与超时；不把 JSON 见证数当作内部全部 fork 数。若程序不提供求解累计时间，明确标注并寻找无需重建的观测方式。

未决：当前二进制是否导出独立求解时间，以及路径摘要能否完整计数，需实跑确认。
