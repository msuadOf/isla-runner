# 显式分支超时定位

目标：区分 flags 算术及 f16→i16 饱和消融中的单次 SMT 长尾与多路径组合，不能将生成 JSON 数当作 fork 数。

范围：只在本目录新增诊断脚本、实验 LD_PRELOAD 和结果；不修改生产源码、默认限时、模型或原 84 次实验结果。使用原冻结程序、IR/config、官方 Z3、QFFP、T1 和配对 seed 17。

步骤：先四臂并行 300 秒诊断采样（不是正式性能验收），记录每次 Z3 check/check_assumptions 的开始、结束及耗时；再对 B 使用现有 fork 日志及定点完整约束与临时 assumptions dump，最多两小时预算。核对源码与实际 IR 的条件、循环及执行顺序，独立查询重放只作为定位，不能替代增量求解结果。

待解：首次 pending 查询是否返回、是否出现连续长尾、Sail lane 运算是否在掩码外求值、实际 fork 数与生产语义是否相同。已有历史 60 秒/qfaufbv/旧 Z3 定位只作历史，不混入当前实验。
