# 执行帧 CoW 合入计划

目标：把旧 `isla-cow-fork` 的容器级写时复制移植到当前 Isla `isarch`（`849900a6`），解决有状态读取回调的路径隔离问题，并归档 MMU 实验结论。

范围：独立候选 `.worktree/isla-cow-local-frame` 的 feature 分支；移植 frame/executor 的共享容器和必要写入口，适配当前路径合并代码。内存契约与共享判定在 memory.rs，SeqMemory／ImmutablePageTables 显式声明纯读取。原实验工作树和无关修改保留。

步骤：先加入共享／分离及内部可变读者回归测试，观察失败；再实现 CoW 与保守深拷贝；运行格式化、执行帧默认和 tracetool 测试，按编译涉及范围补充定向验证；检查本次差异，提交候选并准备主线快进脚本。

验证：官方 Z3 `1fd1d3613`，轻量测试覆盖冻结、恢复、直接 Clone、新调用及兄弟路径读写隔离。保存处理后的命令／计数／结果表，不归档 target、二进制或 IR。

未决：原仓库 `.git` 只读，已实际尝试创建分支并失败。候选用独立 Git 检出；原主线实际快进需可写环境执行交付脚本。第三方若错误声明纯读取或 Clone 仍共享路径状态，普通 Rust trait 无法自动验证；必须明确契约，不承诺不受约束扩展的绝对安全。
