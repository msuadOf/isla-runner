# 分支与合并选择核查计划

2026-10-21。目标：核对 Sail-RISC-V 与 Isla 的实际分支、工作区、父仓 gitlink 和拆分来源，区分内存符号化、浮点、通用支持及可选采样能力，提供合并选择。

范围是 Git 状态、提交图、文件树和既有验证记录。热点为两子仓的本地及缓存远端引用、各 worktree、Isla 的 collector/SMT/配置入口，以及 Sail-RISC-V 三条拆分链。保留全部既有源码、索引、分支及未提交内容；本轮不执行实际 merge、checkout、commit、push 或功能测试。

步骤：读取项目及专题入口；采集 HEAD/索引/工作区和 worktree 状态；核对共同祖先、提交列表与树等价；使用 `git merge-tree --write-tree --name-only` 试算选定分支的文本冲突；比对历史结论；形成报告和可选合并顺序并同步摘要。

验证只支持版本关系、文件树和文本冲突判断，不产生联合候选的功能 PASS。远端使用 `git ls-remote --heads origin` 尝试核实；查询失败则明确区分缓存引用与当前线上状态。完成时复核两子仓各工作树 HEAD、索引条目、补丁和 dirty 文件哈希不变。

未决选择：优先整合全部能力，还是逐项接纳；是否接受 RV64 域约束、采样及向量优化；Sail-RISC-V 使用12提交功能链还是23提交细拆链。
