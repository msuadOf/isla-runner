# 暂存区外内容审计与清理

目标：按用户授权，核对 runner、Sail-RISC-V、Isla 及其 worktree 的未暂存修改和未跟踪文件，删除确认无用的残留。完整历史快照由用户确认完好，本轮不修改快照。

范围：三仓登记的本地 worktree、runner 工作树内同名子模块，以及 `.worktree/` 内实际存在的独立候选树。外部工作树只登记边界。

步骤：列出 Git 状态；按保留分支及组件版本读取源码内容；区分已保留内容、旧实验、运行缓存和独有材料；逐文件执行已确认清理；重新读取 Git 状态并记录处理结果。

热点：`.worktree/unstaged-cleanup-20261109/` 保存逐文件清单与审计工具，主区及各历史树是审查对象。保留暂存区和有效的独有项目记录，不删除整个 worktree 或 Git 元数据。

核对：仅 Git 状态、文本差异和内容阅读。严格禁止运行任何测试、编译、IR 生成或计算及比对哈希。未确认无用的项目保留并说明原因。网络受限时不将本地 origin 缓存说成实时远端证明。
