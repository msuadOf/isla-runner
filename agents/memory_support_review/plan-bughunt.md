# 找 bug 能力改造计划（待用户确认）

日期：2026-09-29。目标：改造 Isla 生成侧 + 重放侧，使工具**天生容易触发已知与未知 bug**。依据：W24 campaign、B1/B2/B3 上游归因、E 线定向复现反馈（进行中）。原则：每项改造都要有"此前因此漏掉的 bug"作为证据，改完用"能自动踩中该类 bug"作为验收。

## 证据底座：我们现在为什么漏 bug

| 缺陷（证据） | 漏掉的 bug（实例） |
| --- | --- |
| **取值退化**：求解器给成功路径挑地址永远对齐（45/45）、基址退化 x0/低位、数据初值全零任意（B2+B3 交叉证实） | #1574（错位 SC，基线含 bug 全漏）、#6486（发 0 不可见）、错位/边界类全部 |
| **编码维度自由求解**：union 参数域整片求解，具体编码（vsseg3e32 等）从未被选中（B3） | #6475（确定性 abort，51 例无一命中）、#6085 |
| **枚举越过 encdec 守卫**：execute 无守卫而 encdec 有（ldu 唯一实证）（B2） | 生成非法变体浪费预算 + 重放死循环 |
| **无分支覆盖账本**：只有 ret_val 直方图，fork 条件无目标化 | 未覆盖分支系统性无人问津 |
| **重放侧**：单指令无序列、ext-missing 静默、错位分歧直接跳过 | LR/SC 对、amocas 背靠背、#6316 类被 preclass 吞 |

## 改造项（第一波，按证据强度与杠杆排序）

### P1 值域 signposting（治"取值退化"——最高杠杆）
- 机制：配置声明"候选值集"（按维度：基址寄存器→{PMA 边界±1、区域边界±1、错位值、低位洞、对齐值}；源数据寄存器→{非零模式：0xA5 步进、掩码、极值}；vl/vstart→{0、1、VLMAX、VLMAX-1、越界+1}）。求解时对每个候选值开一个 goal 批（disjunctive 约束分批求解），等价 isla-testgen 论文的 signposting 思想落地到我们的 solve-state。
- 验收：①错位成功路径从 0/45 → 每配置 ≥N 条（自动踩 #1574 类）；②非零数据注入后 #6486 形态（发 0）在重放层可见。
- 落点：`src/isarch/`（goal 批调度，复用 fork 预算机制）+ 配置语法（`[[value_hints]]`）。

### P2 编码维度预分片（治"整片自由求解"）
- 机制：clause 的编码参数（nf×eew×lmul×width×funct 变体）按维度表**预分片枚举**——每片钉死编码字段、独立预算，替代自由求解撞运气。维度表从 IR clause 参数类型自动导出 + 配置可覆写。
- 验收：VSSEG 全 nf×eew 组合每片 ≥1 条产物（含 vsseg3e32 → E-T1 应能"半自动"命中）；VSX/VLX 用缩小 EMUL 域分片破超时。
- 落点：`src/isarch/exec.rs`（分片调度，扩展 apply_instruction_arg_overrides 思路）。

### P3 encdec 守卫过滤（治 ldu 类）
- 机制：枚举候选编码先过 encdec `when` 守卫求值（模型侧无守卫的 execute 才是求解域），非法编码不进求解；保留显式 opt-in 开关用于故意测保留编码。
- 验收：ldu 变体 gen=0；全 clause 助记符扫描无非法名。
- 落点：`src/isarch/exec.rs` + `isla-lib`（守卫求值复用 W21 的 concretize_symbolic_csrs 机制）。

## 第二波（第一波验收后）

- P4 分支覆盖账本：fork 条件收集 → 目标化未覆盖分支（ Least-covered 优先调度）——接 testgen side-condition 思想。
- P5 bug 模式库：上游 issue 情报 → 配置/值域模板自动生成（locked PMP、跨界错位、边界对）。
- P6 重放侧：短指令序列支持（LR-SC 对、amocas 背靠背）、ext-missing 显式上报、错位分歧从"跳过"改"标记分类输出"。

## 步骤

1. 等收工并入 E 线反馈（哪一步卡手最狠先修哪）。
2. P1/P2/P3 各一个 subagent 实施（TDD），共享 worktree 串行。
3. 验收战役：改造后重跑向量+标量代表 clause → ①四个已知 bug 签名应"无定向参数"命中（或命中难度大降）；②出现已知清单之外的分歧候选 → 逐条分诊（真新 bug / 模型侧 / 环境）。

## 风险

- goal 批数量爆炸（预算调度需限流）；
- P2 分片数 × clause 数的运行成本（按需选片）；
- signposting 可能压缩纯符号路径比例（保留无提示档做对照）。
