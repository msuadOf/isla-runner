# 本轮边界与历史性能依据

历史441c与nan86f的FVFTYPE对照均在约7200秒外限退出124，没有最终完整JSON；局部退休终态分别21和27，未得到总fork数或完成时间加速比。因此本轮按用户要求恢复nan_unbox的原Sail if，不以局部Jump减少宣称整Clause大幅提速。

变更只有boxing检查的一行，保持等宽判断、寄存器访问、canonical NaN定义和其他ITE。当前模型分支提交为9c339044。源码行列未变化，已有workaround坐标不需迁移，仍核对当前132区域和22锚点。

新性能探针使用同一二进制、FD配置和单线程，原始命令与输入哈希见before/和after/。它们用于检查恢复后的实际输出，属于有限预算单次运行，不作为严格性能基准；尤其不能拿超时前的局部终态数作总路径数。

NaN-boxing有效不等于数值一定非NaN；本轮直接恢复的是boxed/unboxed分支。低位的普通数、qNaN/sNaN、Inf等数据条件仍有其他review义务。
